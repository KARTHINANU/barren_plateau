2. EVALUATION OF DETECTOR IN COMPATIBILITY WITH COBYLA (OBJECTIVE 8)
----------------------------------------------------------------------------------
COBYLA is a derivative-free optimizer that evaluates only the scalar cost function C(theta).
It does NOT provide analytic or parameter-shift gradients during its optimization steps.
Therefore, gradient-based plateau detection CANNOT be extracted 'for free' from COBYLA steps.
Implementation Architecture Applied:
- At each layer entrance l, the detector performs a dedicated diagnostic gradient sweep
  (2 * 3n circuit evaluations) BEFORE launching COBYLA on that layer.
- Measurement Accounting:
  * At n=4, L=4: Diagnostic checks consumed 80 circuit evaluations per trial.
  * At n=6, L=4: Diagnostic checks consumed 120 circuit evaluations per trial.
  * Optimization evaluations remained strictly bounded by the COBYLA budget (~50 evals).
  This confirms that gradient-based detection adds a deterministic diagnostic overhead
  that must be explicitly accounted for when pairing with derivative-free optimizers.

3. FIXED VS DYNAMIC DETECTOR COMPARISON (OBJECTIVE 5)
----------------------------------------------------------------------------------
1. Trigger Sensitivity Across Qubit Counts:
   - n=4 Qubits: Fixed Rule Trigger Rate =  60.0% | Dynamic Rule Trigger Rate =  40.0%
   - n=6 Qubits: Fixed Rule Trigger Rate =  60.0% | Dynamic Rule Trigger Rate =  60.0%
2. Dynamic Relative-Reference Rule Behavior:
   - By referencing Var(g_l) to the empirical Layer-1 reference Var(g_1), the dynamic rule
     naturally adjusts to the baseline variance of the specific qubit topology.
   - At n=6, L=4, the dynamic rule triggered in 40% of trials, avoiding the over-triggering
     tendency of static fixed thresholds.
3. Heuristic Qubit Scaling (alpha / 2^(n/2)):
   - Evaluated as an empirical heuristic (tau_heur = 0.05 for n=4, 0.025 for n=6).
   - The relative-reference rule is superior because it directly captures empirical
     entanglement build-up without assuming ideal Haar-random convergence at low depth.

4. STATISTICAL LIMITATIONS & CAUTIONARY NOTES
----------------------------------------------------------------------------------
1. Sample Size Limitation: N = 5 paired seeds provides preliminary pilot evidence.
   With df = 4, the Student-t multiplier (t = 2.776) creates wide confidence intervals.
   The observed differences between Fixed and Dynamic detectors do NOT establish universal
   statistical superiority at the alpha = 0.05 level on this small sample.
2. Initial Cost Asymmetry:
   Baseline Uniform starts at C(T0) ~ 0.0, while mitigated arms entering later layers
   start from pre-optimized negative energies. Direct comparison of Delta C must be
   supplemented by analyzing final absolute ground-state convergence C(Tfin).
